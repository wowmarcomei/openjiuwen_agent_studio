## 一、开发工具要求

| 服务 | 工具 | 版本要求 | 用途 | 版本检查 |
|------|------|----------|------|----------|
| studio-manager / studio-service | JDK | 17+ | Java服务编译运行 | `java -version` |
| | Maven | 3.8.8+ | Java项目构建 | `mvn -version` |
| studio-runtime | Python | 3.11+ | 运行时引擎 | `python --version` |
| | uv | 最新版 | Python包管理（推荐） | `uv --version` |
| studio-console | Node.js | 22.12.0+ | 前端编译运行 | `node -v` |
| | pnpm | 7.0+ | 前端包管理 | `pnpm -v` |

> 各开发工具的安装配置请自行完成，本文档不在此赘述。

## 三、运行前准备

### 1. 下载源码

```bash
git clone https://gitcode.com/openJiuwen/agent-studio.git
```

### 2. 切换分支

进入 `agent-studio` 目录，切换到 `studio-2.0` 分支：

```bash
cd agent-studio
git checkout studio-2.0
```

### 3. 初始化数据库

登录数据库，执行以下语句创建数据库并授权：

> 数据库名可自定义（下方示例使用 `agent_studio`），JDBC 连接串中的数据库名必须与实际创建的数据库名一致。

**MySQL**：

```sql
CREATE DATABASE IF NOT EXISTS `agent_studio` CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
GRANT ALL PRIVILEGES ON `agent_studio`.* TO 'root'@'%' WITH GRANT OPTION;
FLUSH PRIVILEGES;
```

**GaussDB**：

```sql
CREATE DATABASE agent_studio TEMPLATE = templatem ENCODING 'UTF8' DBCOMPATIBILITY = 'M';
```

验证数据库创建成功：

```sql
-- MySQL
SHOW DATABASES;

-- GaussDB
SELECT datname FROM pg_database;
```

> 表结构由 studio-manager 和 studio-service 首次启动时自动创建。

## 四、编译与启动Java服务

### 1. 编译项目

启动 Java 服务前需先编译项目。后续修改 yml 配置无需重新编译，重启服务即可生效；修改 Java 源码后需重新执行以下命令：

```bash
cd backend
mvn clean install "-Dmaven.test.skip=true"
```

### 2. 配置必填项

studio-manager 和 studio-service 共享相同的配置项，分别修改对应的配置文件：

| 配置项 | 环境变量 | 说明 |
|--------|----------|------|
| `spring.datasource.url` | `spring_datasource_url` | 数据库JDBC连接串 |
| `spring.datasource.username` | `spring_datasource_username` | 数据库用户名 |
| `spring.datasource.password` | `spring_datasource_password` | 数据库密码 |
| `redis.host` | `redis_host` | Redis地址，默认 `127.0.0.1` |
| `redis.password` | `redis_password` | Redis密码 |
| `redis.port` | `redis_port` | Redis端口，默认 `6379` |
| `obs.url` | `obs_url` | OBS/MinIO服务地址 |
| `obs.ak` | `obs_ak` | OBS Access Key |
| `obs.sk` | `obs_sk` | OBS Secret Key |
| `obs.bucket` | `obs_bucket` | OBS桶名 |

配置文件位置：

| 服务 | 配置文件 |
|------|----------|
| studio-manager | `backend/studio-manager-service/src/main/resources/application-manager.yml` |
| studio-service | `backend/studio-runtime-service/src/main/resources/application-runtime.yml` |

### 3. 启动 studio-manager

> 需对 studio-manager 进行二次开发时推荐方式一，便于断点调试和热加载。若不修改本模块，仅调测，建议方式二。

**方式一：IntelliJ IDEA**

- 打开主类 `com.openjiuwen.studio.agent.manager.Application`
- 添加 Run Configuration：
  - Main class：`com.openjiuwen.studio.agent.manager.Application`
  - VM options：`-Dspring.profiles.active=manager`

**方式二：命令行**

```bash
cd backend
java "-Dfile.encoding=UTF-8" "-Dloader.path=studio-manager/target/lib/" -jar studio-manager/target/studio-manager-0.0.1.jar --spring.profiles.active=manager "--spring.config.additional-location=studio-manager-service/src/main/resources/"
```

默认端口 `31111`。

### 4. 启动 studio-service

> 需对 studio-service 进行二次开发时推荐方式一，便于断点调试和热加载。若不修改本模块，仅调测，建议方式二。

**方式一：IntelliJ IDEA**

- 打开主类 `com.openjiuwen.studio.agent.runtime.Application`
- 添加 Run Configuration：
  - Main class：`com.openjiuwen.studio.agent.runtime.Application`
  - VM options：`-Dspring.profiles.active=runtime`

**方式二：命令行**

```bash
cd backend
java "-Dfile.encoding=UTF-8" "-Dloader.path=studio-runtime/target/lib/" -jar studio-runtime/target/studio-runtime-0.0.1.jar --spring.profiles.active=runtime "--spring.config.additional-location=studio-runtime-service/src/main/resources/"
```

默认端口 `31113`。

## 五、启动 studio-runtime

### 1. 配置环境变量

```bash
cd agent-runtime
cp .env.example .env
```

编辑 `.env` 文件，配置以下必填项：

```bash
# LLM模型路由（必填）
MODEL_ROUTER_API=http://127.0.0.1:31113/v1/agent-builder

# Redis
REDIS_HOST=127.0.0.1
REDIS_PORT=6379

# OBS对象存储
DATASOURCE_OBS_SERVER=<OBS_URL>
DATASOURCE_OBS_BUCKET=agent-builder
DATASOURCE_OBS_AK=<YOUR_AK>
DATASOURCE_OBS_SK=<YOUR_SK>
```

### 2. 启动服务

```bash
uv run python agent_runtime/EIStart.py
```

默认端口 `31014`。

---

## 六、启动 studio-console

### 1. 安装依赖

```bash
cd frontend
pnpm install
```

### 2. 启动开发服务器

```bash
pnpm start
```

默认访问地址：`http://localhost:4200`
